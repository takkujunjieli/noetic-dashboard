# 因子归因页面

`strategy.html` 现仅加载动量/波动和因子归因。导航入口继续沿用 Qlib；归因计算使用 statsmodels，不运行 Qlib 预测模型。

## 本地使用

启动 `scripts/serve_dashboard.py` 后访问 `strategy.html`：

1. 保存股票池；有修改时先点“更新行情”应用筛选。
2. 点“更新归因”下载公开因子与含分红复权行情。
3. 选择过去5/20/60日，选股票或点击表格股票代码查看各项贡献。

更新失败保留上次报告。行情与归因共享一个后台任务锁。静态发布只读 `data/factor_attribution.json`，不开放本地刷新。

## 解释

实际收益分解为无风险、市场、行业独立部分、规模/价值/盈利/投资/动量和未解释贡献。单位 pp 是收益百分点。未解释贡献展开为截距与残差。R²来自此前252日估计窗口，不代表未来准确率。

行业ETF先对共同因子去重；该约定将共享部分优先归于市场/风格。当前行业代理人工维护，可能包含目标股票，且不代表历史成分。未映射标的不强行归因。

含分红收益与上方不含分红动量口径不同。French 因子可能滞后，页面明确给出归因、行情和因子日期；未发布日期不会补零。该模型是统计解释，残差不是已验证 alpha。

计算入口为相邻 `factor-research/run_factor_attribution.py`；依赖 `requirements-attribution.txt`，模型方法与对账约定见该项目 `docs/factor-attribution-v1.md`。
